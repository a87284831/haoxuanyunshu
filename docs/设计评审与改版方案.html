问题诊断（按严重度排序）

每条均附代码证据，可直接复查
P0 严重

用 Emoji 当图标 —— 全站最大的"廉价感"来源

侧栏 11 个模块、全部二级菜单、工作台 KPI 卡、通知铃铛、更新日志入口，共 69 处直接使用系统 Emoji 作为图标。

问题在于：Emoji 由操作系统渲染，Windows / macOS / 手机端字形完全不同（同一图标在 Win10 是彩色扁平，在 iOS 是拟物渐变），无法控制颜色、粗细与尺寸，永远无法与品牌色对齐。这是企业系统里"看起来像个人项目"的第一识别特征。

用户感知：打开系统第一眼就是彩色小表情，与"管理几十人薪资、上百万采购额"的重量级业务形成强烈错配。

nav/menus.jsicon: '👥''📊 数据驾驶舱'home/Home.vue🔔📋⊡
P0 严重

96 种颜色、827 处硬编码，四套设计体系并存

全站硬编码了 96 个不同色值、共 827 次出现，并且明显是四套体系混用：

① 主框架沿用 #0f2557 藏蓝 + #2563eb；② 组织架构模块整段改用钉钉/Arco 配色 #165dff / #1f2329 / #f2f3f5；③ 审批与报表又用 #3b82f6 / #1e293b；④ 财务模块单独 finance.css。

结果：同一个"蓝色主按钮"在不同页面是 4 个不同颜色；同一个"成功绿"是 #16a34a 或 #00b42a；同一个"危险红"是 #dc2626 或 #f53f3f。用户跨模块使用时，色彩语义会失效。

styles/legacy.cssfinance.css#1f2937 / #1f2329 / #1e293b / #262626 四种"深色文字"
P0 严重

没有设计令牌，改一次主题要改 800 处

全站 0 个 CSS 变量（除浏览器默认）。圆角出现 5 / 6 / 7 / 8 / 9 / 10 / 11 / 12 / 14px 十种；阴影至少 6 种不同写法；卡片内边距在 14 / 16 / 18 / 20 / 22px 之间随机。

直接后果：① 无法做暗色模式；② 无法整体换肤；③ 新页面只能靠"复制粘贴旧页面"保持一致，越做越乱；④ 每次改版都要人工逐页核对。

P1 重要

卡片风格停留在 2018：8px 圆角 + 1px 硬阴影 + 彩色竖条标题

主用卡片是 border-radius:8px + box-shadow:0 1px 3px rgba(0,0,0,.05) + h3 左侧 3px 蓝色竖条。这套组合是 Bootstrap 4 时代的典型写法，特征是"像贴纸一样浮在白底上"，缺乏层次。

而报表、工作台、组织架构三个较新的模块已经改用 12px 圆角 + 柔和双层阴影，同一个系统里出现了两种卡片质感，同屏对比时能看出明显代差。

legacy.css .card.rpt-kpi (12px).home-kpi (12px).org-card (12px)
P1 重要

表格：全网格线 + 12.5px 小字 + 无斑马 + 无对齐策略

所有单元格都带 1px 边框，形成密集网格，视觉噪音大；正文 12.5px 偏小，长表格阅读疲劳；数字列虽然用了 tabular-nums，但列宽不稳定；行高仅约 28px，密集数据（薪资 200+ 人）容易串行。

建议：去掉竖线只留横向分隔，表头浅灰底 12px 大写间距，行高 40–44px，首列加粗，数字列右对齐，悬浮行浅蓝高亮。

table.tb th,td{border:1px solid}font-size:12.5pxpadding:7px 8px
P1 重要

顶栏层级薄弱，且与侧栏争抢注意力

顶栏 52px 内塞了「渐变实心大按钮 + 16px 粗体标题 + 铃铛」，其中 .al-btn 的深蓝渐变按钮是全屏最重的视觉元素，抢走了页面标题的注意力。而真正需要突出的"当前页面 / 面包屑"只有 16px 文本。

建议：顶栏 56px，左侧「模块名 / 页面名」两级面包屑（12px 灰 + 15px 深），"全部模块"改为无底色描边图标按钮，右侧统一头像/通知，视觉重量从"按钮"转移到"信息"。

legacy.css .topbar.al-btn.topbar .title
P1 重要

13 个模块各配一个高饱和纯色，九宫格像色卡

模块色板为 #2563eb / #e74c3c / #8b5cf6 / #3b82f6 / #1e40af / #f59e0b / #16a34a / #14b8a6 / #6366f1 / #0d9488 / #0ea5e9 / #ef4444 / #64748b——饱和度、明度完全不统一（#0d9488 与 #ef4444 并排放，视觉上"一沉一跳"）。

建议：统一为同一明度带的柔和色（H 从 210→280 均匀分布，S 45%、L 52%），或退一步：全部用中性灰底 + 单一品牌蓝图标，只在 hover 时出彩色，最高端。

nav/menus.js APPS[].color
P2 建议

登录页是模板化渐变 + 两个白圆

左侧 linear-gradient(135deg,#0f2557,#1e3a8a,#2563eb) 加两个 rgba(255,255,255,.06) 圆形装饰，右侧白卡配 20px 标题——这是 2018 年免费后台模板的标准样式，且登录页是全系统"第一印象"、最值得做品牌的地方。

legacy.css #loginPage → .login-brand::before/::after
P2 建议

字体、数字与空状态

① 全站单一 "微软雅黑" 字体栈，未使用系统级字体（macOS 上会退化成劣质渲染）；② 数字未全局启用 tabular-nums，金额列滚动时宽度抖动；③ 列表为空时只有一行灰字，无插画/引导按钮；④ 无加载骨架屏，切页时白屏闪。

body{font-family:"微软雅黑"}
03

三套高端化方向

请从中选择一套，或指定"推荐方案 + 局部混搭"
方向 A

沉稳商务 · 藏蓝金

保留深蓝侧栏，收敛为单一藏蓝 + 少量暖金点缀

  • ＋ 与现有侧栏风格延续，改动最小、风险最低
  • ＋ 适合国企/物业类客户对"稳重"的偏好
  • ＋ 深色侧栏天然形成视觉分区
  • － 仍然偏"传统后台"，年轻感与科技感不足
  • － 藏蓝+金容易滑向"金融/政务"气质
方向 B · 推荐

现代中性 · 石墨蓝

浅灰底 + 白卡 + 细边框 + 单品牌蓝，图标全改线性 SVG

  • ＋ 信息密度最高的同时最"干净"，适合数据密集型后台
  • ＋ 与 Element Plus 原生视觉最兼容，改造成本可控
  • ＋ 天然支持暗色模式（只需切换令牌）
  • ＋ 线性图标 + 单色系统，专业感提升最明显
  • － 需要一次性统一 4 套配色，工作量集中在前两批
方向 C

深色驾驶舱

整体深色外观，数据大屏质感，图表发光

  • ＋ "数据驾驶舱"模块观感最强，演示效果极佳
  • ＋ 图形与数字在深色上对比度更高
  • － 长时间录入薪资/采购单据，深色反而增加眼疲劳
  • － 打印、导出、报表类页面必须另做浅色版，双套成本
  • － 全站改造量最大，且不适合一线填报人员
我的建议：以 方向 B 作为全站主视觉；方向 C 只用于「数据驾驶舱 / 报表大屏」类页面（做成深色主题变体，共用一个令牌文件切换），其余录入型页面保持浅色。这样既拿到高端观感，又不牺牲填写效率。
