## 一、项目概述

物业公司内部一体化管理系统，薪酬核算为核心，覆盖人事、考勤、绩效、财务、采购、维保、审批、报表。

- 单租户内部系统（约 73 名管理人员 + 各项目员工），月度批量核算为主
- 后端 Laravel 11 API（`/api/*`），前端 Vue3 SPA（history 模式，base `/app/`）
- 本地 SQLite 开发，生产 MySQL（阿里云 ECS，nginx + php-fpm）
- 四种薪酬人员类型：`staff` 项目员工、`case` 案场、`manager` 管理、`hq` 总部
- 三种绩效发放方式：`monthly` 月度绩效法、`quarterly` 分期兑现绩效法（季度+半年度比例）、`quarter_grade` 季度绩效法（按薪酬档位决定季度型/月度型）

### 总体架构

```
浏览器 (Vue3 SPA, /app/)
   │  fetch /api/*  (Bearer token / session)
   ▼
nginx ── try_files → public/index.php ── Laravel 路由 (routes/api.php)
                                            │
              ┌─────────────────────────────┼──────────────────────────┐
              ▼                             ▼                          ▼
      Http/Controllers/Api           Services（核算/规则/钉钉）    Finance/Purchase（handler 风格）
              │                             │
              ▼                             ▼
                     MySQL（生产）/ SQLite（本地）
                     legacy_json_snapshots（配置权威存储）+ data/*.json（镜像）
                     钉钉开放平台 API（花名册全量同步/事件回调）
```

### 薪酬核算关键口径
- 月绩效基数 = `fixed_monthly − base_salary`
- 季度型（quarter_grade + mode=quarter，仅经理级）：季度中月份绩效=0；季度末月（4/7/10/1）发
  `季度系数 × Σ(月绩效基数 × perf_att/req_att)`，无比例、无半年度
- 月度型（主管级/专员级）：每月 `月绩效基数 × 出勤比例 × 当月月度系数 coef`
- quarterly（旧）：季度末发 `Σ基数 × 季度系数 × quarter_ratio`，7 月追加 H1 半年度
- 失败必须显式：missing_coef / missing_pay_grade / invalid_pay_grade / missing_pay_rule
- 个税：独立计税，入职月起仅累计本系统收入与已扣税；5000 起征
- 历史导入行 archived=true，重算只删当月（where year_month=$ym），归档行进快照保全
